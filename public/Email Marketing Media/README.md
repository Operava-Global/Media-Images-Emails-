## What belongs here

Use this folder for approved, reusable visual assets created for marketing emails and campaign communications, including:

- Email campaign hero banners and header graphics
- Service-line promotional images for IT, Cloud Computing, Intelligent Automation, and Global BPO
- Campaign-specific promotional tiles and call-to-action graphics
- Product, solution, and industry visuals approved for OPERAVA marketing
- Seasonal campaigns, event announcements, and corporate announcements
- Supporting illustrations, icons, and branded visual elements

## Brand and quality requirements

- Follow the approved OPERAVA brand identity and the current mandatory email-template design.
- Keep the visual system consistent: premium charcoal/dark-gray foundations, OPERAVA orange accents, white/light text where appropriate, and legible contrast.
- Use only approved OPERAVA logos, marks, slogans, and service descriptions.
- Do not stretch, recolor, distort, or recreate the logo without brand approval.
- Keep important text out of image-only artwork where possible; campaign copy and calls to action should remain live HTML text in the email.
- Design for email-safe rendering and mobile viewing. Avoid tiny text, excessive detail, and edge-to-edge critical content.
- Use descriptive filenames in lowercase kebab-case where practical, for example `it-services-hero-2026-11.jpg`.
- Prefer optimized JPEG for photographic artwork, PNG for transparency, and WebP for web-only assets when the consuming email clients and delivery path support it. For maximum email-client compatibility, use JPEG or PNG.
- Use accurate file extensions matching the actual file format so static hosting sends the correct MIME type.
- Optimize file size while preserving readability and image quality. Add meaningful alt text in the email HTML.

## Publishing and URL rules

- Keep published files inside this directory so the existing GitHub Pages workflow includes them automatically.
- Use URL-encoded spaces in public links, e.g. `https://media.operavaglobal.com/Email%20Marketing%20Media/campaign-hero.jpg`.
- Use stable, versioned filenames for campaign assets. Avoid replacing an asset in place when an already-sent email depends on it; publish a new version instead.
- Do not place credentials, private customer information, internal-only documents, editable source files containing confidential material, or unapproved third-party assets in this public folder.
- Confirm rights/licensing and approval before publishing externally.
